# hand_gestures_controlled_LED_matrix_system
Real-time webcam hand-gesture controller for ESP32, 5 PWM LEDs, and an 8x8 MAX7219 LED matrix using Web Serial &amp; Bluetooth Classic. Supports 4 interactive modes: palm toggle (✓/✕), pinch dimmer (0–99%), sequential finger counter (0–5), and 5-bit finger-to-decimal converter (0–31)
